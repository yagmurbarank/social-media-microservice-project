# 🚀 Microservices Basics with Spring Boot & Spring Cloud

This project is a **learning-based microservices application** built to understand the fundamentals of microservice architecture using Spring Boot and Spring Cloud.

It includes basic implementations of service separation, configuration management, and inter-service communication.

## 📌 Project Overview

The goal of this project is to explore how microservices are structured and how core components work together in a simple setup.

## 🧱 Modules

- **User Microservice**  
  Handles basic user-related operations.

- **Auth Microservice**  
  Responsible for authentication logic and user validation.

- **Config Server**  
  Centralized configuration management using Spring Cloud Config.

## ⚙️ Technologies Used

- Java 8+
- Spring Boot
- Spring Cloud Config
- REST APIs
- Maven

## 🔑 What I Learned

- Fundamentals of microservices architecture
- How to design and split applications into independent services
- Centralized configuration management using Spring Cloud Config Server
- Inter-service communication using REST APIs
- Structuring backend services in a modular and maintainable way
- Building and organizing multi-module projects
- Implemented centralized configuration using Spring Cloud Config Server with Git-based configuration management
- Connected microservices to Config Server for dynamic and externalized configuration
- Containerizing applications using Docker
- Using Redis for caching and performance improvement
- Basics of Kubernetes and deploying applications on Google Cloud (GKE)
- Using OpenFeign for service-to-service communication
